# Raio de Sol — Clínica de Estética Avançada

Site institucional responsivo desenvolvido com Python e Flask.

## Como executar

1. Crie e ative um ambiente virtual.
2. Instale as dependências: `pip install -r requirements.txt`
3. Inicie o site: `python index.py`
4. Acesse `http://127.0.0.1:5000`

O formulário de avaliação direciona o visitante ao WhatsApp da clínica com uma mensagem personalizada.
